# Nickel Frontend

Single-spa storefront for Nickel. The shell loads the catalog, cart, and account apps.

## Roadmap

- Improve the UI and UX of the shop, catalog, cart, and account flows.
- Continue the microfrontend split as new storefront features land.
- Add a video player for product video.
- Add motion and transitions between pages and catalog states.
- Add holiday themes.
